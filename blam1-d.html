Editing Kit Suites

[]Halo Editing Kit - Gearbox

Shipped with the 2003 PC port of Halo: Combat Evolved. (download link provided by c20)

[]Invader - An opensource alternative

incredibly powerful toolset made by the community and supports every version of Halo: Combat Evolved/Blam! 1. Does Not Support Opensauce tags, and version differing tags probably aren't comptatble with each other. Linux Compatable

[OP][DISCORD]Mozz's Editing Kit (MEK) - Opensource python alternative/complement.

Another, python based alternative to the HEK. MEK tools offer compatability to Custom Edition & MCC . Mo's tools are able to extract tags from .map files, importing and exporting tag blocks. It can also deprotect maps that were made during the height of Custom Edition. OP support has long been abandoned, so community members have made sporatic patches. Discord link will be the latest known version. Opensauce Compatable. Linux Compatable

Halo 1 Tools/Supplements

[]Chimera - SnowyMouse

A Custom Edition clientside mod that brings countless of fixes, QoL, and other features such as auto map downloads. Essential for CE 2026

[]HAC2 - Devieth(current maintianer, i guess.)

The OtherTM clientside mod for CE. Old, and 99% sure development is not a thing. but added fov so neat.

[][DOCS]Opensauce (OS) - Extended Modding, Sacrifical Frames

Opensauce opened up the Blam! engine to modders and tinkerers with extended modding support such as new script functions, tag extentions, shader extentions, Post Processing, directional lightmaps,etc. An example of this would (regretably) be SPV3.

[]Halo CE MAX Toolkit - Mark Mc'Fuzz

3dsMax Plugin for Halo CE/Blam1

[c20]Aether - TheFieryScythe

Lightmap tool, just found it. Sounds awesome

Defunct tools [c20]

If youre at all interested. Halo modding has been around a long while with little or bare support which resulted in the community having to do the heavy lifting for themselves.

About

Originally in 1999, developed as a Mac Sci-Fi RTS, the Blam! engine eventually would power the ancient, epic, and mysterious world of Halo: Combat Evolved. Later in 2003, Halo: Custom Edition released on PC would open the door for creative & passionate fans to create their own worlds within the engine.
